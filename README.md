# 📌 Form Data Mahasiswa

## 📝 Deskripsi
Project ini dibuat untuk memenuhi tugas Interaksi Manusia dan Komputer (IMK).  
Aplikasi ini berupa form input data mahasiswa berbasis web menggunakan HTML, CSS, dan JavaScript.

---

## 🎯 Tujuan
- Memahami dasar HTML, CSS, dan JavaScript
- Membuat form input data
- Mendesain tampilan yang menarik dengan CSS

---

## ⚙️ Fitur
- Input data mahasiswa (NIM, Nama, Alamat, dll)
- Menampilkan data ke tabel
- Edit data
- Hapus data
- Tampilan sudah menggunakan CSS modern

---

## 🛠️ Teknologi
- HTML
- CSS
- JavaScript
